产品概述

云胶片是面向医疗机构的数字胶片与检查服务云平台。患者可通过手机、微信公众号或扫码，安全查看检查报告与医学影像；医院在统一后台完成配置、运维与统计，并与现有 RIS/PACS 对接，无需替换院内核心业务系统。

为谁解决什么问题

角色常见痛点云胶片价值
患者排队取片、胶片易丢、复查带盘不便线上查看报告与影像，减少往返
临床科室患者频繁咨询报告是否已出支持患者自助查询，减轻窗口压力
影像科 / 信息科系统多、对接成本高可配置对接，按需接入院内数据源
医院管理使用情况难统计、分享难管控提供访问记录、分享管理与审计能力

产品特点

  • 多端覆盖：患者端支持手机浏览器、公众号、扫码入口；管理端浏览器即用
  • 轻量对接：通过数据库、存储过程或 Web 接口接入，改造量可控
  • 灵活配置：验证方式、影像浏览、短信网关、展示页面均可后台配置
  • 影像方式多样：支持院内影像库、网络取图、本地归档等对接方式
  • 部署灵活：支持云端、私有化、容器化部署，可运行于 Windows / Linux
  • 安全可管：身份验证、链接时效、水印脱敏、权限与访问审计可配置

主要能力

患者侧

  • 身份确认：支持检查号、手机号验证码等方式（可配置组合）
  • 查看内容：检查详情、电子报告、影像浏览（CT/MR/DR 等）
  • 分享检查：可生成分享链接，支持水印控制与访问记录追踪

入口方式

  • 二维码：检查单/报告单扫码进入对应检查，验证后查看
  • 公众号：与医院公众号对接，链接支持签名与有效期控制

医院侧

  • 检查管理：查询检查、维护联系方式、控制是否允许线上查看
  • 业务配置：验证方式、影像浏览、短信网关、界面展示统一维护
  • 使用统计：按入口来源、设备类型等维度统计使用情况
