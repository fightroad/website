产品简介

DICOM Viewer 是一款基于现代 .NET 技术栈构建的医学影像（DICOM）查看与工作站级浏览工具。面向医院、影像中心及医疗团队，提供从单机阅片到局域网协同的影像浏览解决方案，帮助医生更高效地查看与分析影像数据。

核心优势

  • 上手简单：操作逻辑贴近常见影像工作站，学习成本低
  • 轻量部署：基于 .NET / Windows 平台，可独立使用或嵌入现有 HIS/RIS/PACS
  • 性能稳定：提供完善的日志记录与日志查看工具，便于运维与远程诊断
  • 可定制扩展：模块化架构，便于二次开发与功能扩展

功能预览

适合对象

  • 需要一款稳定可靠、可二次开发的 DICOM 查看器的团队
  • 希望降低部署和维护成本的医院与影像中心
  • 正在搭建或扩展自有医学影像平台的技术团队
适用对象医院影像科、影像中心、医疗技术团队
